# Contract examples (synthetic)

Request and response fixtures for API contract version 1.0.0. They are generated by a scripted run of the real application against a throwaway database (`apps/api/scripts/generate_examples.py`), so they match runtime behaviour.

- `*.request.json` is the request body. `*.response.json` is `{ "status": <HTTP status>, "body": <JSON or null> }`.
- IDs, tokens (`example-token-not-real`) and timestamps are **synthetic**. Service content comes from the reviewed seed knowledge.
- `apps/api/tests/test_contract.py` validates every file against the Pydantic contract.
- `apps/web/src/mocks/fixtures.gen.ts` is generated from these files (`pnpm --filter @navination/web mocks:sync`) and type-checked against the OpenAPI types.
